# 🍕 Food Delivery Website

A responsive **Online Food Delivery Website** developed using **HTML, CSS AND Java Script**. The website provides a user-friendly interface for browsing food items, cart  management, exploring restaurants, and accessing food delivery services.

## 🚀 Project Overview

This project is a frontend-based food delivery website designed to provide users with a simple and attractive online food ordering experience.

The website includes a responsive layout, food images, navigation sections, restaurant/food presentation, contact section, and mobile-friendly styling.

## ✨ Features

* 🏠 Home page with attractive food delivery interface
* 🍔 Food and restaurant sections
* 📱 Responsive design for desktop and mobile devices
* 🎨 Clean and user-friendly UI
* 🖼️ Food and restaurant images
* 📞 Contact section
* 🔐 Login/Sign-in interface
* 🔍 Easy navigation between website sections
* 📱 Mobile responsive CSS using `phone.css`

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **Responsive Web Design** – Mobile and desktop compatibility
* **VS Code** – Development environment
* **Git & GitHub** – Version control and project hosting

## 💻 How to Run the Project

1. Clone this repository:

```bash
git clone https://github.com/avinashraw231216-design/food-delivery-website.git
```

2. Open the project folder in **VS Code**.

3. Open `index.html`.

4. Run the project using **Live Server** or open `index.html` directly in your browser.
